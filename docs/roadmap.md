# Roadmap

## How to read this

Phases are ordered by dependency and risk, not by date: later phases assume the safety net,
security fixes, and cache/model understanding built by the earlier ones are in place. Nothing
here is scheduled — it's a sequence, not a sprint plan, and a phase can be skipped deliberately
if it stops being worth doing.

Each item links to an upstream issue (`cola-laits/linguistics_research_center#NNN`) or a section
of the platform review (`docs/reports/2026-09-15-platform-review.md`) so the motivation can be checked against
a primary source. Status values: **Proposed**, **In progress**, **Done**, **Sent upstream** (a PR
opened against `cola-laits`), **Dropped** (considered and abandoned, with a note why). Every
phase-0 item is In progress, since that phase is the current work; everything else is Proposed.
