# Glossary

Domain and project terms a new contributor or coding agent will meet in this repository.
Alphabetical; entries name the model, table, or route in `server/app` where relevant.

**/admin vs /admin2** — `/admin` is the Filament 5 panel (`server/app/Filament`), the maintained
admin interface. `/admin2` is the legacy Vue 3 lesson editor (`routes/web.php`, prefix `admin2`),
kept alive only because Filament's series-editor widget still links out to it.

**ADR** — Architecture Decision Record: a short, dated document for one decision and its
consequences, filed separately from this glossary and roadmap.

**cognate** — Words in related languages descended from the same etymon: the `LexReflex` rows
sharing a `LexEtyma` via the `lex_etyma_reflex` pivot.

**COLA** — UT Austin's College of Liberal Arts, which houses LAITS and the LRC.

**cross-reference** — A typed link between two entries. `LexReflexCrossReference` is a pivot with a
translatable `relationship` label linking reflex to reflex and is in active use.
`LexEtymaCrossReference` does the same for etyma but is a dead, unused model (review §3).

**data cache** — `lex_lexicon_data_cache`: one precomputed JSON blob per reflex per viewer locale,
built by `app:generate-lexicon-data-cache` and read by the public Data page and search API instead
of the live tables. Regenerated by hand after bulk edits.

**DRAVIDILEX** — The Dravidian-languages lexicon, imported via `app:import-dravidilex-csv`; the
best-behaved of the three CSV importers.

**EIEOL** — Early Indo-European Online Lessons, the lesson series; structurally independent of the
IELEX/multi-lexicon side, though a gloss can link to an etymon.

**EIEOL hierarchy** — Under an `EieolSeries`: ordered `EieolLesson`s, each with `EieolGrammar`
sections and ordered `EieolGlossedText` passages, each with ordered `EieolGloss` rows (one per
glossed word/phrase), each with ordered `EieolElement`s pointing to an `EieolHeadWord` (optionally
a `LexEtyma`).

**etymon / etyma** — The ancestral word an entry is built around; stored as `LexEtyma` with a
translatable `gloss` and a many-to-many link to its `LexReflex` descendants. "Etyma" is the plural
and what the model/table names use.

**experiment branch** — A long-lived `exp/<topic>` branch for an unproven direction: sent upstream
via `upstream-pr/<topic>` if it pans out, dropped otherwise.

**extra data** — Arbitrary key/value metadata beyond an entry's fixed columns: `LexEtymaExtraData`
and `LexReflexExtraData`, each with a translatable `value`.

**Filament** — The PHP admin-panel framework (v5.7) rendering `/admin`, built on Livewire; resources
live under `server/app/Filament` and `server/resources/views/filament`.

**gloss** — Two senses: the translatable `gloss` field on `LexEtyma`/`LexReflex` (a word's meaning
in the viewer's language), and `EieolGloss`, an EIEOL-hierarchy row for one glossed word or phrase.

**headword / head word** — The citation form heading an entry — the etymon or reflex form itself in
IELEX-style views, or `EieolHeadWord`, the distinct EIEOL model for the word being taught.

**IELEX** — The Indo-European Lexicon, served two ways: legacy `/lex` Blade views on `lex_*` tables,
and the newer `/lexicon/ielex` route through the multi-lexicon framework.

**LAITS** — Liberal Arts Instructional Technology Services, the UT Austin unit maintaining
upstream.

**language family / subfamily** — `LexLanguageFamily` and `LexLanguageSubFamily` group a lexicon's
`LexLanguage`s: subfamily belongs to family, language to subfamily, all scoped per `LexLexicon`.

**/lex vs /lexicon** — `/lex` is the original IELEX-only Blade front end. `/lexicon/{slug}` is the
newer, lexicon-agnostic framework serving IELEX, SEMITILEX, MAYALEX, DRAVIDILEX through shared
views. Both render IELEX independently and can drift.

**lexicon (and slug)** — A `LexLexicon` row is one dictionary: its own languages, semantic
categories, sources, and viewer-language options. `slug` drives `/lexicon/{slug}` routing and the
column switch in `LexLexicon::getDataColumns()`.

**Livewire** — The reactivity library Filament is built on: server-rendered components that
re-render over AJAX with no separate JS framework needed.

**MAYALEX** — The Mayan-languages lexicon, imported via `app:import-mayalex-csv`; its importer has
known bugs (a commented-out transaction, timestamp-suffixed slugs on rerun).

**part of speech** — `LexPartOfSpeech` rows, scoped per lexicon; a reflex's parts of speech are
stored in display order via the `LexReflexPartOfSpeech` pivot, not a single field.

**Pokorny** — Julius Pokorny's *Indogermanisches etymologisches Wörterbuch*; "the Pokorny index" is
IELEX's proto-language master list of etyma at `/lex/master`.

**proto-language** — The reconstructed ancestor of a lexicon's family (e.g. Proto-Indo-European).
`LexLexicon` carries a translatable `protolang_name` and `protolanguage_page_content`.

**reflex** — A language-specific descendant of an etymon; stored as `LexReflex`, belonging to one
`LexLanguage`, with a translatable `gloss`, linked to `LexEtyma` via `lex_etyma_reflex`.

**semantic category vs semantic field** — A two-level meaning taxonomy after C.D. Buck's
*Dictionary of Selected Synonyms*: `LexSemanticCategory` (e.g. "The Body") is the broad,
per-lexicon grouping; `LexSemanticField` (e.g. "head, skull") belongs to one category and is what
etyma are tagged with, via `lex_etyma_semantic_field`.

**SEMITILEX** — The Semitic-languages lexicon, imported via `lrc:protosemitic_import`; per the
platform review it is published but functionally empty in production (no proto-language name, no etyma).

**source (bibliographic)** — `LexSource` rows, scoped per lexicon, giving a reflex a citation
(`code`, `display`) via `LexReflexSource` — distinct from a data-import source file such as a CSV.

**Starling format** — The tab-delimited export format from the Tower of Babel / STARLING project; a
historical reference for IELEX's structure. Current importers read plain CSV instead.

**upstream (in this repo's sense)** — `cola-laits/linguistics_research_center`, maintained by LAITS
and mirrored read-only into this fork's `upstream` branch. Sending something upstream means a PR
from `upstream-pr/<topic>` back to that repository.

**viewer language** — The locale a visitor reads a lexicon in, distinct from its data languages.
Configured via `LexLexicon->viewer_lang_options` and resolved through Spatie `HasTranslations`
fields plus the `switch_lang` route.
